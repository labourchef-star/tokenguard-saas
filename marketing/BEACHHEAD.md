# Loop Stop — Beachhead (v1 ads)

## Primary beachhead (ONE)

**Claude Code users who already run tools / PreToolUse hooks (or will install a plugin).**

### Why this one

1. **Detector fit:** The product ships a real Claude Code–style PreToolUse path and plugin tree — not a bolted-on afterthought.  
2. **Distribution fit:** Plugin / settings.json / marketplace-add matches how this audience installs middleware. GitHub zip still covers the dashboard.  
3. **Message fit:** “Sticky tool loop” is visible in Claude Code sessions; less education than generic “token guard.”  
4. **Acquisition research:** Claude path ranked strong secondary overall, but **best paid-attention beachhead** because Angle 4 converts on a named workflow; GitHub/Gumroad remain the artifact channels for everyone.  
5. **Scope control:** Grok/OpenAI-compatible `base_url` stays supported and documented, but v1 **ad creative and $40/week** aim at Claude Code first so create-demand spend does not fragment.  
6. **Explicit non-beachheads for v1 spend:** Cursor marketplace/localhost Base URL promises, game-dev agents, broad “AI productivity” audiences.

### What “winning” looks like (14 days after first spend or first 50 organic downloads)

- Majority of signup client mix = Claude Code (or Both)  
- Hook/plugin install documented in ≥30% of ahas  
- Impact aha: Demo SIMULATED complete **or** ≥1 live block within 24h of integrate  
- Kill-rule sheet respected if ads are on  

### Ad posture

- **Create-demand:** yes, conditional — DEMAND keyword weak; educate with Demo, do not raise budget past $40/week.  
- **Money Engine:** Pass = Fail (off-engine). Beachhead validates willingness to install local tooling, not engine greenlight.  
- **Spend:** $0 until human enables; then $40/week hard cap + FUNNEL.md kill rules.
