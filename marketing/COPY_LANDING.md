## Section: What it does

Coding agents sometimes get stuck: re-reading the same file, re-running a failing command, or bouncing between two tools. Each sticky loop burns tokens.

Loop Stop:

1. Detects those patterns locally  
2. Blocks or annotates them (threshold you control)  
3. Shows estimated token waste avoided on `http://127.0.0.1:8788/`

Also ships a Claude Code–style PreToolUse hook so Claude Code users get the same detector without requiring the proxy for every call.
