# Pattern Interruption angles — Loop Stop beachhead

**Audience (now):** coding-agent users — Claude Code + Grok / OpenAI-compatible.  
**Later pack (do not lead with):** game-dev agent loops (asset re-import, build fail ping-pong).  
**Hard rule:** no AI clichés (Revolutionize, Delve, Elevate, Tapestry, Supercharge, seamless, unlock, harness, etc.).

Savings copy must say **estimate** unless provider usage. Demo proof must say **simulated**.

---

## 1. The fifth Read

**Hook:** “Your agent just re-read the same file for the fifth time.”  
**Pain:** Sticky Read loops feel like progress; they are meter burn.  
**Proof:** Demo seeds repeated-read sessions; Impact shows blocked calls + est. tokens avoided.  
**CTA:** Try simulated demo → Sign up → Integrations (Claude Code hook).

## 2. Compile-fail karaoke

**Hook:** “Same bash command. Same error. Third chorus.”  
**Pain:** Agents retry identical failing shell/compile commands until the budget dies.  
**Proof:** Loop detector blocks N-identical Bash; baseline vs with-stop tool counts.  
**CTA:** Demo mode → install hook or proxy.

## 3. Who paid for the ping-pong?

**Hook:** “Two tools. Same args. You’re still watching.”  
**Pain:** Tool A ↔ Tool B with identical arguments looks busy and costs real tokens.  
**Proof:** Blocked tool events on the session timeline.  
**CTA:** Open dashboard after Demo seed.

## 4. Claude Code without a cloud nanny

**Hook:** “PreToolUse can say no before the meter moves.”  
**Pain:** Claude Code users see loops in-session; they want a local stop, not another SaaS.  
**Proof:** Plugin / settings.json hook path; optional dashboard for Impact.  
**CTA:** Sign up → Integrations → “I’ve installed the hook.”

## 5. Grok proxy, local guardrail

**Hook:** “Point base_url at localhost. Keep the key on your machine.”  
**Pain:** OpenAI-compatible SDKs talk straight to the provider; nothing watches for sticky loops.  
**Proof:** Proxy at `http://127.0.0.1:8788/v1` + env/local key (never logged).  
**CTA:** Sign up → paste key on Integrations → first live chat.

## 6. Estimates with a spine

**Hook:** “We’ll show you 75% — and label it simulated.”  
**Pain:** Tooling that invents dollar savings burns trust.  
**Proof:** Honest badges: estimate / provider / demo. Demo Impact ≈ 75% est. waste reduction.  
**CTA:** Try demo; then connect live traffic for provider-labeled usage when available.

## 7. Install once, not subscribe to your own tokens

**Hook:** “We sell software. We don’t skim your prompts.”  
**Pain:** Hosted “AI gateways” add COGS and latency for a problem that is local.  
**Proof:** Zip + `./install.sh`; SQLite on disk; optional `HOST=0.0.0.0` on your VPS.  
**CTA:** Download after signup; Gumroad when human publishes.

## 8. Overnight agent, morning invoice

**Hook:** “You left it running. It left the loop running.”  
**Pain:** Unattended coding agents amplify sticky patterns while you sleep.  
**Proof:** Session list with blocked counts; Impact aggregate.  
**CTA:** Demo → then live proxy before the next long run.
