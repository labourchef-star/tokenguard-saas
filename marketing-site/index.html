FAQ

Is the 75% number real traffic?

No. It comes from a simulated Demo mode that seeds sticky FakeAgent sessions. Live savings depend on your traffic and are labeled estimate unless the provider returns usage.

Is this a cloud product?

Yes — a hosted SaaS proxy is live at tokenguard-saas.onrender.com. A $19 local zip also exists on Gumroad (draft until payout is connected).

Which agents work?

Grok / xAI via OpenAI-compatible proxy, Claude Code via PreToolUse hook/plugin, and any client that accepts a custom base_url (Continue, Cline, scripts).

Do you store my API keys in the cloud?

Keys stay on the machine running the app (env or local opaque storage). They are never logged.

How do I get it?

Open Sign up → create an account → copy your base_url and tg_ key → point your agent at /v1. Or try the simulated Demo first.
