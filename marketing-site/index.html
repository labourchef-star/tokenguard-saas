What burns tokens while you watch

Sticky Read loops

Same file, same offset — again. The agent “checks once more.” The meter keeps spinning.

Compile / bash fail loops

Command fails. Agent retries the identical command. Fail. Retry. Fail. Budget gone.

Tool ping-pong

Two tools bounce the same args. TokenGuard notices and can block before the next round.

FAQ

Is the 75% number real traffic?

No. It comes from a simulated Demo mode that seeds sticky FakeAgent sessions. Live savings depend on your traffic and are labeled estimate unless the provider returns usage.

Is this a cloud product?

Yes — a hosted SaaS proxy is live at tokenguard-saas.onrender.com. A $19 local zip also exists on Gumroad (draft until payout is connected).

Which agents work?

Claude Code via one-command plugin (PreToolUse hook — no URL config). Grok / xAI and other OpenAI-compatible clients via hosted base_url (advanced).

Do you store my API keys in the cloud?

Keys stay on the machine running the app (env or local opaque storage). They are never logged.
