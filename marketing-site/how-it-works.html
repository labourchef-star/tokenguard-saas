Claude Code: one command

No base_url. No unpack zip. Demo mode needs no API key.

Install

/plugin install tokenguard --marketplace labourchef-star/tokenguard-saas

Shell: claude plugin install tokenguard --marketplace labourchef-star/tokenguard-saas

1. Run the command

Adds the GitHub marketplace and enables the TokenGuard PreToolUse hook.

2. Keep coding

Sticky Read/Bash loops are blocked locally. No URL pointing.

3. Optional dashboard

Sign up on the hosted SaaS for impact charts — not required for Claude.

Grok / xAI

Paste API key (local opaque storage). Point SDK base_url at http://127.0.0.1:8788/v1. Proxy forwards to xAI and runs loop detection.

Claude Code (primary)

OpenAI-compatible / Cursor (advanced)
