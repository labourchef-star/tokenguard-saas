Install TokenGuard

Local PreToolUse hook. No base_url, no proxy pointing, no ANTHROPIC_BASE_URL.

Primary — Claude Code session 
/plugin install tokenguard --marketplace labourchef-star/tokenguard-saas
Or from your shell 
claude plugin install tokenguard --marketplace labourchef-star/tokenguard-saas

Installs the hook from the GitHub marketplace. Sticky Read/Bash loops get blocked locally.
